# Portafolio

## Arfert: sistema de operación en campo
App móvil, API REST y panel web para gestionar jornadas de ruta, visitas con GPS, ventas de mostrador y checklist de vehículos. Funciona sin conexión y sincroniza al recuperar señal.
**Mi rol:** desarrollo full stack, despliegue y soporte.
**Stack:** React Native, Expo, TypeScript, AdonisJS, PostgreSQL, React, Vite, Tailwind CSS.

## Arfert: sistema de Talento Humano
Aplicación web con API para gestionar colaboradores, documentos, permisos, vacaciones, incapacidades y reportes, con roles, auditoría y carga segura de archivos.
**Stack:** Angular, NestJS, Prisma, PostgreSQL, Tailwind CSS.

## DAC: planificación y seguimiento de visitas
App móvil, API y panel web para planificar visitas de técnicos y verlas con GPS en un mapa en vivo, con alertas de atrasos y llegadas fuera de rango.
**Stack:** React Native, Expo, AdonisJS, PostgreSQL/Supabase, React, Leaflet.
